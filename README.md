# MDA-Win8086 Simulator — Enhanced Version

This project is based on the original MDA-Win8086 simulator created by **Hamza Alshafe**.

I received permission from the original author to modify the code, fix errors, and improve the simulator.

### My modifications
- Fixed bugs in the simulator.
- Added support for more instructions.
- Made additional improvements to the simulator.
- Improved the user interface

### Credits
Full credit for the original simulator goes to its original creator. This repository contains my modifications and improvements to the original work.

The goal of this project is to build upon the original simulator, improve its functionality, and make it more useful for students learning 8086 assembly.

The original: https://github.com/HamzaAlshafe/mda-win8086-simulator
